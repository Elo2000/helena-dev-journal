What is a Closure?
I like to think of a closure using two different perspectives:

The Simple way 
Imagine a closure is like a remote control that stays linked to a specific room. Even if you leave the room and close the door, the remote still works! It remembers exactly what was in that room. It can change things inside (like the volume) from the outside.
No one else can walk into that room and mess with things directly—they have to use the remote.

The Technical way
In programming terms, a closure is a function that has a "memory." When you create a function inside another function, the inner one "remembers" the variables and the environment it was born in. Even after the outer function has finished running, the inner function keeps a private link to those variables.
